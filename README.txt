REQUIREMENTS
  JDK 17 or higher
  Download from: https://adoptium.net

PROJECT STRUCTURE
  src/foodordering/        Java source files (12 files)
  compile_and_run.bat      Windows launcher
  compile_and_run.sh       Linux / macOS launcher
  PROJECT_REPORT.md        Full project report (Markdown)
  README.txt               This file

HOW TO RUN
  Windows  : Double-click compile_and_run.bat
  Linux/Mac: ./compile_and_run.sh
  Manual   : javac -d out -sourcepath src src/foodordering/*.java
             java -cp out foodordering.Main

RECEIPTS
  Saved automatically to receipts/ folder in the same
  directory as the launcher after each confirmed order.
